# 03 — 收支表派生指标与月份范围选择

**What to build:** 用户在收支表上看到这段时间的总收入、总支出、结余、储蓄率和峰值月，每月支出构成的堆叠条，每行一条迷你趋势条；能自己选看几个月；当月没过完、或有外币交易没算进来时都有提示。

所有派生数字都由前端从同一份矩阵推导，不新增接口：

- 总支出 / 总收入取两个根行各月之和；结余 = 收入 − 支出；储蓄率按 `CONTEXT.md` 定义，收入为零显示「—」。
- 峰值月取支出根行最大的那一列。
- 每月构成取支出下第一层子行；迷你趋势条直接画该行的各月金额。
- `partial` 的列头标注「截至 MM-DD」；`skipped_currencies` 非空时标注「有外币交易未计入」。
- 收支表有自己的月份范围选择，统计页顶部的「本月 / 本周 / 本年」切换不再驱动它。

规格：[spec.md](../spec.md)「前端」一节。
