# 04 — 点格子下钻到流水

**What to build:** 用户点收支表里某个分类某个月的格子，页面切到「流水」标签，只列出该账户（含子孙账户）在那个月的流水，钱具体花在哪一眼可见。

复用现有的交易列表接口，带上账户前缀和该月起止日期。流水页目前的时间范围只来自页面顶部的单区间切换，需要先让它能接受外部传入的自定义范围（和账户前缀），再接上下钻。

规格：[spec.md](../spec.md)「前端」一节中的下钻。

**Blocked by:** 02 — 收支表基础矩阵

**Status:** ready-for-agent

- [ ] 流水页能接受外部传入的自定义起止日期与账户前缀，并在页面上显示当前范围
- [ ] 点收支表格子切到「流水」标签，范围为该月 1 日到月末（当前月截到今天），前缀为该行账户
- [ ] 点汇总账户的格子，列出其全部子孙账户的流水
- [ ] 下钻后的流水笔数与金额合计和格子金额对得上（手动验证）
- [ ] 从下钻状态切回顶部区间切换时，流水页恢复正常行为
