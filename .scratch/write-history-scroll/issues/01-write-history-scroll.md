# 01 — 写入历史卡片限高并在内部滚动

**What to build:** 对话页右栏 Ledger tab 里的写入历史卡片不再随记录条数无限撑高，改成下面这样：

- 标题栏「写入历史」固定不动，下面的列表区最多大约 5 条记录高（约 320px）。超出的部分在卡片内部上下滚动。
- 滚到列表的顶部或底部之后，继续滚动不会带动右栏。
- 记录少时，卡片按内容收缩（用最大高度，不用固定高度）。
- 只作用于写入历史卡片，其他卡片和右栏整体的滚动都不变。后端和 `ledger_history_limit` 配置都不改。

详见 [spec](../spec.md)。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent
