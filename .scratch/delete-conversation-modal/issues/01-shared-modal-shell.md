# 01 — 抽出通用 modal 外壳，账目页删除交易弹窗改用它

**What to build:** 把账目页删除交易弹窗的蒙版和卡片抽成一个通用的 modal 外壳，放进前端通用 UI 模块，从入口导出。外壳负责：

- 蒙版和居中卡片
- 按 Esc 关闭
- 打开时把焦点放到调用方指定的元素上
- busy 期间不可关闭

卡片里的内容由调用方决定。点蒙版永远不关闭，外壳也不提供开关。

账目页删除交易弹窗改用这个外壳，版式（待删除原文预览、底栏的文件和行号、「确认删除」按钮）保持不变，行为改为：

- 点蒙版不关闭
- 按 Esc 关闭
- 打开时焦点在「取消」
- 请求进行中 Esc 和「取消」都无效

详见 [spec](../spec.md)。

**Blocked by:** None — can start immediately

**Status:** ready-for-agent

- [ ] 通用 modal 外壳已从前端通用 UI 模块的入口导出，复用现有的 `.scrim` / `.modal` 样式。
- [ ] 账目页删除交易弹窗的外观和改动前一致：原文预览、底栏文件和行号、「取消」和「确认删除」按钮都在。
- [ ] 点蒙版不关闭弹窗。
- [ ] 按 Esc 关闭弹窗，账本不变。
- [ ] 弹窗打开时焦点在「取消」，直接按回车不会删除。
- [ ] 点「确认删除」后，请求返回前 Esc 和「取消」都无法关闭弹窗。
- [ ] 删除失败时弹窗保持打开并显示错误；删除成功后弹窗关闭，撤销入口照常出现并可用。
- [ ] 窄屏下弹窗不超出屏幕宽度。
- [ ] 前端构建（含类型检查）通过，后端 pytest 全部通过。
