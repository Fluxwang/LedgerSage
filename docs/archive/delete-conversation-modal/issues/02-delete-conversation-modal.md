# 02 — 删除对话改用紧凑款 modal 确认

**What to build:** 在左栏对话菜单里点「删除」时，不再弹浏览器原生确认框，改为用 01 的通用外壳弹出紧凑款确认弹窗：标题、正文，右下角放「取消」和危险样式的「删除」，不带底栏。弹窗状态由对话页统一管理，同一时间最多显示一个。

流程：
1. 先重新拉一次对话列表，拿到这条对话最新的待确认写入笔数。这一步失败或对话已不存在时，不弹窗，错误显示在对应行上。
2. 拉取成功后打开弹窗。
3. 点「删除」后进入 busy。
4. 成功：关闭弹窗，从列表移除这条对话；如果删的是当前对话，切到新对话。
5. 失败：弹窗保持打开，在正文下方显示错误，按钮恢复可点。

文案：
- 标题：删除对话？
- 正文：「{对话标题}」会从对话列表中移除，账本不受影响。
- 待确认笔数大于 0 时追加一行：其中 {N} 笔待确认的记账会一并丢弃。

不写「不可撤销」，因为「撤销」专指对账本写入做 git revert。后端不改动。详见 [spec](../spec.md)。
