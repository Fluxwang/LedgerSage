# 写入历史卡片限高并在内部滚动

Status: done

术语以 [`CONTEXT.md`](../../CONTEXT.md) 为准。本期不新增术语，也不新增 ADR。**写入历史 (Write History)** 指 LedgerSage 替用户做过的写入（记账、设预算、删除），按时间倒序排列。

## Problem Statement

- 对话页右栏的 Ledger tab 里，写入历史卡片没有高度限制。有多少条记录，卡片就撑多高。
- 后端最多返回 10 条，每条占三到四行，卡片能拉得比一屏还长，把右栏整体撑高。
- 用户想看写入历史时，只能滚动整个右栏，diff 卡和预算进度会跟着被滚出视野。

## Solution

- 写入历史卡片的标题栏固定不动，下面的列表区设一个最大高度，大约 5 条记录的高度。超出的部分在卡片内部上下滚动。
- 滚到列表的顶部或底部之后，继续滚动不会带动右栏。
- 记录不满 5 条时，卡片按内容收缩，不留空白。

## User Stories

1. 作为用户，我希望写入历史卡片的高度有上限，这样不管有多少条写入，右栏都不会被撑得很长。
2. 作为用户，我想在写入历史卡片内部上下滚动，查看更早的写入。
3. 作为用户，我希望滚动写入历史时，标题栏「写入历史」一直可见。
4. 作为用户，我希望滚动写入历史时，上方的 diff 卡和预算进度保持不动。
5. 作为用户，我希望滚到写入历史顶部或底部后继续滚，不会带动整个右栏。
6. 作为用户，我希望列表区大约显示 5 条记录，这样不用滚动就能看到最近几次写入。
7. 作为用户，当写入不满 5 条时，我希望卡片只占内容需要的高度，不出现一大块空白。
8. 作为新用户，在还没有任何写入时，我希望看到「还没有 LedgerSage 写入」的提示，提示框是正常大小。
9. 作为用户，确认一笔记账、删除一笔交易或撤销一次写入以后，我希望写入历史刷新，并显示在最顶部，这样能马上看到刚才那次写入。
10. 作为用户，我希望已撤销的写入在可滚动的列表里还是用灰色显示，并带「已撤销」标记。
11. 作为用户，我希望滚动条只在内容超出时出现。
12. 作为用户，我希望用鼠标滚轮、触控板和触屏都能在卡片里滚动。
13. 作为用户，在写入历史加载中或加载出错时，我希望看到的提示和现在一样。
14. 作为用户，我希望右栏变矮（例如浏览器窗口变小）时，右栏整体仍然可以滚动，能看到写入历史卡片。

## Implementation Decisions

- 只改前端样式：给写入历史卡片的列表区加一个专用修饰类，设最大高度（约 320px，相当于 5 条记录），`overflow-y: auto`，`overscroll-behavior: contain`。标题栏不在滚动区内。
- 用最大高度，不用固定高度：记录少时卡片按内容收缩。
- 只作用于写入历史卡片，不改通用卡片样式。diff 卡、预算进度、Accounts tab 的卡片都不受影响。
- 右栏整体的滚动区域保持不变。
- 刷新时，加载态会替换掉列表内容，滚动位置自然回到顶部，不需要写额外的滚动复位逻辑。
- 后端不改动。写入历史接口仍然最多返回 `ledger_history_limit` 条（默认 10），配置不改。

## Testing Decisions

- 本期不新增测试接缝，也不引入前端测试框架。这次只改样式，在仓库现状下没有合适的自动化方式来测试。
- 好的验证只看外部可观察的行为：卡片多高、哪里滚动、滚动会不会带动右栏，而不看具体用了哪些 CSS 属性。
- 验收分三层：
  1. 前端构建通过（含 TypeScript 类型检查）。
  2. 后端 pytest 全部通过。后端没有改动，写入历史接口已由写入历史相关测试覆盖。
  3. 在浏览器里手动走一遍以下清单：
     - 写入超过 5 条时，卡片列表区约 5 条高，可以在内部滚动；标题栏固定不动。
     - 滚到列表顶部或底部后继续滚，右栏不动。
     - 写入只有 1～2 条时，卡片按内容收缩，没有滚动条。
     - 没有写入时，空状态提示显示正常。
     - 在卡片里滚到下方后，确认一笔记账（或删除、撤销一次写入），列表刷新并回到顶部，新写入在第一条。
     - 已撤销的写入仍是灰色，带「已撤销」标记。
     - 有 diff 卡时右栏仍可以整体滚动，写入历史卡片高度不变。
     - 浏览器窗口变矮时，右栏仍可以整体滚动到写入历史卡片。

## Out of Scope

- 调整后端返回条数，或者在卡片里做分页、「加载更多」。
- 改动 diff 卡、预算进度、Accounts tab 等其他卡片的高度或滚动行为。
- 改动右栏整体布局，比如让写入历史占满右栏剩余空间。
- 自定义滚动条样式。

## Further Notes

- 如果以后觉得 10 条不够，可以调 `ledger_history_limit`。限高以后，多返回几条也不会撑长页面。
