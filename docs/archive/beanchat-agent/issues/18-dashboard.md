# 18 · 仪表盘端点与页面

Status: open
Milestone: M2
Blocked by: 17

## 背景

仪表盘是确定性的聚合查询，走**专用 REST 端点**，不经过 Agent——不该花 LLM 的钱，也不该有不确定性（ADR-0006）。

## 要做什么

端点（按设计稿的四块内容）：

- 账户余额卡片（现金 / 微信 / 支付宝 / 信用卡待还，含本月变动）
- 月度支出趋势（近 6 个月）
- 分类支出（用 `name:` meta 的中文显示名，票 06）
- 最近记账（分页）

页面按设计稿实现：`stat-grid` 四宫格、SVG 折线图、`cat-list` 条形、`table` 明细，以及本周/本月/今年的时间范围切换。

## 完成标准

- 数字与直接跑 BQL 一致。
- 分类名显示中文，来源是账本 meta 而非前端硬编码。
- 时间范围切换真实生效。
- 空账本（新注册用户）不报错，显示合理的空态。
