# 20 · 决策历史页与 runs 分页接口

Status: open
Milestone: M3
Blocked by: 14

## 背景

设计稿第三个视图：左侧运行列表 + 右侧详情时间线，支持按 `全部 / 有追问 / 记账 / 查询` 过滤。

## 要做什么

- `GET /runs`：分页 + 按意图/是否有追问过滤。
- `GET /runs/{id}`：完整 steps。
- 历史页按设计稿实现：`hist-row` 列表（运行号、标题、时间、意图标签、耗时、状态徽标）+ 详情面板复用票 14 的时间线组件。
- 「导出 JSON」按钮：导出单次运行的完整轨迹。
- 运行标题自动生成（如「记录火锅支出（含追问）」），可由 Reply 节点顺带产出。

## 完成标准

- 过滤器真实生效，「有追问」筛出的确实是含 ASK 步骤的运行。
- 详情页的时间线与当时实时看到的一致。
- 「回放这次运行」按钮：明确其语义（本期实现为静态回放动画即可，不重新调用 LLM）。
