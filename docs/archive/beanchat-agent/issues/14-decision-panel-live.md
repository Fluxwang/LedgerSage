# 14 · 决策面板实时渲染

Status: open
Milestone: M1
Blocked by: 12, 13

## 背景

对话页右侧那块固定深色的决策面板，是这个项目最有辨识度的部分。

## 要做什么

- 用 `fetch` + `ReadableStream` 手工读 SSE 分帧（`EventSource` 带不了 `Authorization` header）。
- 时间线随事件逐格长出：`step-dot` 三态（未开始 / 进行中脉冲 / 已完成）、耗时、代码块 payload、chips（置信度证据）。
- 面板头部：运行号、模型名、工具调用次数、总耗时、token 数。
- 追问事件渲染成对话里的快捷回复按钮，点击即作为下一条消息发出。
- 断线处理：流中断时面板显示明确状态，不要停在「运行中」的假象上。

## 完成标准

- 记一笔带追问的账，面板的六格时间线实时长出，与设计稿 Run #1482 的信息密度一致。
- 展示的置信度数字来自票 09 的真实频次统计，不是硬编码。
- 刷新页面后能从决策历史里翻到同一次运行（票 20）。

## 注意

设计稿里的耗时数字（128ms / 204ms）是编的，真实 LLM 往返是几百毫秒到数秒——UI 要能容纳更长的数字和更长的等待。
