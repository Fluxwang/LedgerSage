# 08 — 前缀不存在时如实回答，并给出相近账户

**What to build:** 即使有了账户表（06），模型仍然可能填一个不存在的前缀。现在这种情况会被答成「这个范围内没有找到记录」，用户会以为这段时间真的没花钱。这张票在三个工具执行之前先做校验：如果规范化后的前缀下面没有任何已开户的账户，就**不执行查询**，由代码生成回复（不再调用 LLM），说明账户不存在，并给出最多 3 个相近的账户。

这一期不转成追问：追问恢复后会重新分类意图，现在没有「带着选中的账户回到查询」的路径，以后需要时再单独做。

详见 spec 的「查询账户前缀」一节。
