# 01 — 账户显示名迁移

**What to build:** 追问的候选按钮、账户树和确认卡里显示中文账户名，而不是英文账户路径。用户说「饭卡」时系统也能凭中文名找到对应账户。

现存账本里 106 个账户一个都没有把中文名写在 `open` 指令的 `name:` meta 上——中文写在行尾注释里，Beancount 不会把它当 meta，于是账户显示名（ADR 0009）这条喂给 LLM 的语义信号是空的。仓库里已有一个迁移工具做这件事，只是从没对这本账本跑过。

其中 94 个账户有行尾中文注释，可自动迁移。剩下 12 个没有注释，需要人工拟定中文名后写入；这 12 个里有 10 个是收入账户，正是本期主线最需要名字的那一批。账本文件里的分组注释（如「;红包」「;上学生活费」）可以作为拟名依据，拟好后需用户逐个确认。

这是对账本已有行的**改写**，属于追加式写入（ADR 0002）之外的例外，与删除（ADR 0013）并列。迁移在账本仓库中单独提交；执行前工作区必须干净，执行后要重新加载账本确认没有破坏语法。

**Blocked by:** None — can start immediately
